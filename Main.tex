\section{Introduction}

Ground-based astronomical spectra are affected by absorption in the Earth's atmosphere. These telluric absorption features contaminate the observed spectrum and can interfere with the detection and analysis of astrophysical spectral lines, particularly when stellar and atmospheric features overlap in wavelength. Accurate modelling and correction of telluric absorption is therefore an essential step in the reduction and interpretation of many spectroscopic observations.

Telluric transmission can be estimated from observations of standard stars obtained close in time and airmass to the science target. This approach requires additional observing time and must account for intrinsic features in the standard-star spectrum and differences in atmospheric conditions. Alternatively, synthetic atmospheric transmission can be fitted directly to suitable science spectra, reducing the need for separate calibration observations \citep{MOLECFIT1}.

\Molecfit\ implements this model-based approach by combining atmospheric profiles, molecular spectroscopic data, and radiative-transfer calculations with models of the instrumental response and observed continuum \citep{MOLECFIT1}. Its performance has been evaluated on astronomical observations \citep{MOLECFIT2}, making it an established method for telluric correction.

Here we introduce \pymolfit, an independent Python implementation of the established physical approach underlying \molecfit. Its purpose is to bring spectral preparation, atmospheric fitting, and correction into a unified workflow that integrates with Python-based analysis. Automated region selection and optional interactive editing support this process without introducing a new physical formalism. Because an independent numerical implementation need not reproduce identical fitted transmissions, we assess \pymolfit\ against \molecfit\ using matched inputs for optical HARPS and infrared CRIRES+ spectra.

\section{\Pymolfit\ framework}

The project began with the aim of simplifying the installation and use of \molecfit\ by packaging it within a Python environment while preserving its calculations and behaviour. During development, we found that integrating the existing software and its dependencies was less practical than implementing the correction workflow directly in Python. We therefore developed \pymolfit\ as an independent implementation using Codex AI coding tools, rather than as a Python interface to the existing executables.

The resulting framework provides its own interface and automated processing features, with installation through the Python package environment. Parameter fitting, calculation of atmospheric transmission over the full spectral range, and application of the telluric correction are combined in a single function, \texttt{correct()}. This function accepts spectrum files, loaded spectrum objects, or wavelength--flux arrays and returns the corrected spectrum together with the fitted transmission, model parameters, masks, and diagnostic information.

\Pymolfit\ automatically divides the spectrum into processing segments while preserving spectral-order and detector-group boundaries. Fitting regions can be selected automatically or inspected and edited interactively. When a theoretical stellar spectrum is supplied, it can be used to identify stellar features and exclude them from telluric parameter estimation. These exclusions affect only the fit; atmospheric transmission is still calculated in the excluded regions when applying the correction.

The core approach remains that of \molecfit: constructing an atmospheric model, fitting its predicted transmission to the observation, and using the fitted transmission to remove telluric absorption \citep{MOLECFIT1,MOLECFIT2}. The physical methods are established, but \pymolfit\ performs its own numerical calculations without executing \Molecfit\ or \LBLRTM. Differences in data handling, numerical implementation, and optimisation can therefore produce different transmission spectra and fitted parameters. These implementation differences are summarised in Tables~\ref{tab:physical_implementation} and~\ref{tab:fitting_implementation}, and the resulting corrections are compared in Sect.~\ref{sec:validation}.

\section{Methodology}
\subsection{Atmospheric profile and absorption calculation}

\Pymolfit\ follows the atmospheric-profile construction used by \molecfit\ \citep{MOLECFIT1}, combining a MIPAS reference atmosphere \citep{MIPAS_PROFILE} with GDAS pressure, temperature, and water-vapour profiles \citep{GDAS}. Conditions at the observation time are estimated from a time-weighted average of the bracketing GDAS profiles. When these are unavailable, \pymolfit\ uses the same two-month average profiles as \molecfit. Available local weather measurements adjust the lowest layers. The molecular number density at altitude \(h\) is
\begin{equation} n_s(h) = x_s(h)\,\frac{P(h)}{k_{\mathrm B}T(h)}, \end{equation}
where \(x_s\) is the number fraction of species \(s\), \(P\) and \(T\) are pressure and temperature, and \(k_{\mathrm B}\) is Boltzmann's constant. The line-of-sight column density through layer \(i\) is
\begin{equation} N_{s,i} = \int_{\mathcal{L}_i} n_s[h(\ell)]\,\mathrm{d}\ell, \end{equation}
where \(\mathcal{L}_i\) is the light path within the layer and \(\ell\) measures distance along it. The path is calculated from the observation airmass, supplied explicitly or read from metadata, accounting for spherical geometry and atmospheric refraction.

Absorption is evaluated on a grid finer than the detector sampling. The AER catalogue \citep{AER} supplies line positions, integrated strengths \(S_j(T_{\mathrm{ref}})\), and broadening parameters at \(T_{\mathrm{ref}}=296\,\mathrm{K}\) \citep{HITRAN}. Defining the wavenumber \(\tilde{\nu}=1/\lambda\), where \(\lambda\) is wavelength, the cross section for transition \(j\) in layer \(i\) is
\begin{equation} \sigma_{j,i}(\tilde{\nu}) = S_j(T_i)\,\phi_{j,i}(\tilde{\nu}). \end{equation}
Here, \(S_j(T_i)\) is the strength adjusted to the layer temperature \(T_i\), and \(\phi_{j,i}\) is the effective Voigt-based profile. Local pressure, temperature, and composition determine the line position and Doppler and collisional broadening. The discrete-line optical depth is
\begin{equation} \tau_{\mathrm{lines}}(\tilde{\nu}) = \sum_i\sum_s N_{s,i}\sum_{j\in s}\sigma_{j,i}(\tilde{\nu}), \end{equation}
where \(j\in s\) denotes transitions of species \(s\). Enabled atmospheric continuum contributions, including water-vapour and carbon-dioxide absorption, give an additional optical depth \(\tau_{\mathrm{cont}}\) \citep{MTCKD,LBLRTM}. The total optical depth and Beer--Lambert transmission are \citep{RYBICKI1979}
\begin{equation}
    \begin{aligned}
        \tau_{\mathrm{atm}}(\tilde{\nu}) &= \tau_{\mathrm{lines}}(\tilde{\nu})+\tau_{\mathrm{cont}}(\tilde{\nu}),\\
        T_{\mathrm{atm}}(\tilde{\nu}) &= \exp[-\tau_{\mathrm{atm}}(\tilde{\nu})].
    \end{aligned}
\end{equation}
Here, \(T_{\mathrm{atm}}\) is the intrinsic atmospheric transmission, before detector sampling and instrumental broadening.

\subsection{Spectral segmentation and fit-region selection}
\begin{figure*}[t]
    \centering
    \includegraphics[width=\textwidth]{Images/Interactive_selector.png}

Green and orange shading mark fitting and stellar exclusion intervals; exclusions take precedence where they overlap. Automatically generated regions can be inspected and edited using the line-selection and stellar-template controls. Blue ticks mark H$_2$O transitions from the AER catalogue.}
    \label{fig:Interactive_selector}
\end{figure*}

\Pymolfit\ divides the spectrum into processing segments while preserving spectral-order and detector-group boundaries, identified from metadata or inferred from large wavelength gaps. The default target width is 50\,\AA, with further subdivision if the atmospheric grid exceeds two million points per segment. These configurable limits control memory use without coarsening the model grid.

Fitting regions focus parameter estimation on telluric absorption, while exclusion regions remove stellar features or defective pixels that could bias the fit. Only valid pixels within fitting regions and outside exclusions contribute to the comparison between the observed spectrum and the model.

The function \texttt{select\_telluric\_regions()} automatically generates fitting windows around a requested number of AER transitions. Transitions are ranked by
\begin{equation}
    A_j = S_j(T_{\mathrm{ref}})\,N_{s(j),\mathrm{rep}},
\end{equation}
where \(S_j(T_{\mathrm{ref}})\) is the reference strength of transition \(j\), and \(N_{s(j),\mathrm{rep}}\) is the column density of its species \(s(j)\) in a fixed reference atmosphere. The highest-scoring lines within the observed coverage are selected. Each window extends a configurable number of detector pixels on either side of its line centre; the defaults are 100 lines and a half-width of 12 pixels. Lines in wavelength gaps are skipped, and overlapping windows are merged.

Enabling the interactive editor displays the generated intervals for inspection and manual adjustment (Fig.~\ref{fig:Interactive_selector}). Fitting and exclusion intervals can then be saved together in an Character-Separated Values format (ECSV) file and supplied to the correction.

When no fitting regions are supplied to \texttt{correct()}, it selects them automatically using the same ranking score, but distributes the selected lines across wavelength and molecular species and adapts window widths to the estimated instrumental broadening.

Stellar exclusions can be generated from a theoretical stellar spectrum. \Pymolfit\ continuum-normalises the template, broadens it for stellar rotation and, when a resolving power is supplied or available in the metadata, instrumental resolution. The template is converted to the observation's wavelength medium and reference frame using the stellar radial velocity and observation frame correction. Features exceeding a specified fractional deviation from the template continuum define exclusion intervals. These intervals are widened by a configurable velocity margin to include line wings and allow small alignment errors.

\subsection{Spectral modelling and parameter estimation}
With the fitting and exclusion regions defined, \pymolfit\ performs preliminary fits to representative telluric-rich regions to select the wavelength-correction and instrumental-broadening models. It compares the original wavelength calibration with constant, linear, and, where supported, quadratic corrections for each spectral order or detector group. Instrumental broadening initially uses a Gaussian profile; additional Lorentzian wings or wavelength-dependent widths are retained when justified by the preliminary comparisons. The main fit then refines the selected models using all fitting regions.

Both stages construct the predicted flux in the same way. Species optical-depth contributions are calculated in advance for the reference atmosphere. At each trial, molecular scaling factors, initially unity, multiply these contributions before they are summed to calculate \(T_{\mathrm{atm}}\). Composition-dependent line widths and nonlinear continuum contributions are not recalculated as these factors change. The trial wavelength correction is applied, and the transmission is averaged over each observed pixel's wavelength interval before convolution with the normalised instrumental line-spread function. This processed transmission is denoted by \(\widehat T_{kp}\) at pixel \(p\) in segment \(k\). Only the model is resampled; the observation remains unchanged.

A local polynomial continuum scales the transmission to the observed flux level:
\begin{equation}
    C_{kp} = \sum_{m=0}^{d} c_{km}u_{kp}^{m},
    \qquad
    F^{\mathrm{mod}}_{kp} = C_{kp}\,\widehat T_{kp}.
\end{equation}
Here, \(c_{km}\) is the coefficient of polynomial term \(m\) in segment \(k\), \(d\) is the continuum order, and \(u_{kp}\) maps wavelength linearly from \(-1\) to \(+1\) across the segment. The initial continuum is quadratic, \(d=2\). This flux continuum is distinct from the atmospheric continuum absorption in \(\tau_{\mathrm{cont}}\).

The model is compared with the observed flux inside the fitting regions using the soft-\(L_1\) objective implemented in SciPy's \texttt{least\_squares} routine \citep{SCIPY}\footnote{\url{https://docs.scipy.org/doc/scipy/reference/generated/scipy.optimize.least_squares.html}}:
\begin{equation}
    \begin{aligned}
        r_{kp}
        &= \frac{F^{\mathrm{obs}}_{kp}-F^{\mathrm{mod}}_{kp}}
                 {\sigma_{F,kp}}, \\
        \mathcal{J}
        &= a^2 \sum_k \sum_{p\in\mathcal F_k}
        \left[\sqrt{1+\left(r_{kp}/a\right)^2}-1\right].
    \end{aligned}
\end{equation}
Here, \(F^{\mathrm{obs}}_{kp}\) is the observed flux, \(\sigma_{F,kp}\) its uncertainty, and \(\mathcal F_k\) contains the valid fitting pixels after exclusions. The dimensionless scale \(a\), initially unity, controls the reduced influence of large residuals. Supplied uncertainties are used unchanged; otherwise, they are estimated from local pixel-to-pixel fluctuations.

A bounded trust-region reflective optimiser iteratively updates the molecular scales and enabled wavelength and broadening parameters, recalculates the model, and evaluates \(\mathcal{J}\). Molecular scales are fitted logarithmically and shared across segments, while atmospheric pressure and temperature profiles remain fixed. Wavelength corrections are shared within each physical order or detector group. At each trial, continuum coefficients are determined independently for each segment by iteratively reweighted linear least squares. Iteration stops when an objective-improvement, parameter-step, or gradient criterion is met; reaching the evaluation limit instead does not establish convergence.

After a successful initial main fit, alternative continuum orders are tested on temporarily withheld wavelength blocks with the fitted transmission held fixed. The quadratic is retained unless validation favours an alternative. The residual scatter may also update the robust-loss scale \(a\). When required, the main fit is repeated with these updated settings.

With the final parameters fixed, \pymolfit\ evaluates the transmission over the full input wavelength coverage, including transitions outside fitting regions and within excluded intervals. The corrected observed flux is
\begin{equation}
    F^{\mathrm{corr}}_{kp}
    = \frac{F^{\mathrm{obs}}_{kp}}{\widehat T_{kp}},
\end{equation}
where \(\widehat T_{kp}\) now denotes the final fitted transmission. This step applies the correction without further fitting. The continuum is retained; only atmospheric transmission is divided out.

\section{Validation}\label{sec:validation}

We assess \pymolfit\ against \molecfit, an established telluric-correction package with published performance evaluations \citep{MOLECFIT1,MOLECFIT2}. The comparisons use HARPS and ESPRESSO spectra and a CRIRES+ extraction. For each observation, both programs independently fit the same spectrum and uncertainties, using matched atmospheric inputs, spectroscopic data, and fitting and exclusion regions.

\subsection{Na\,I D comparisons}

Figure~\ref{fig:validation_comparisons} (top) shows the Na\,I D region in $\beta$~Pictoris observed with HARPS on 6 April 2017 and AU Mic observed with ESPRESSO on 8 July 2023. The HARPS panel is extracted from the full-spectrum correction, which fits H$_2$O and O$_2$ columns and includes weak CO absorption at its reference abundance.

For AU Mic, both programs fit the telluric interval at 592.05--592.22\,nm, outside the broad stellar Na\,I absorption, using a quadratic continuum, a constant wavelength shift, and a fitted Gaussian instrumental width. The fitted transmission is then evaluated across the doublet. Within each panel, the original and corrected spectra share one constant flux scale. The corrected spectra closely overlap, although the telluric features in this ESPRESSO observation are comparatively weak.

\subsection{Atmospheric transmission comparisons}

We compare the fitted transmissions on the observed detector grid, including wavelength correction and instrumental broadening. Their relative difference at pixel $p$ in segment $k$ is
\begin{equation}
    \Delta_{kp}
    = \frac{\widehat T^{\mathrm{Py}}_{kp}}
           {\widehat T^{\mathrm{MF}}_{kp}} - 1.
\end{equation}
Positive values indicate higher transmission predicted by \pymolfit; negative values indicate lower transmission. Ratios use valid pixels where both transmissions are at least 0.1, without wavelength binning, a stellar reference, or additional normalisation.

The middle figure in Fig.~\ref{fig:validation_comparisons} shows the HARPS comparison over 560--610\,nm. Across the full available coverage, approximately 378--691\,nm, the mean absolute relative difference is $\langle|\Delta|\rangle=9.44\times10^{-5}$ over 309\,719 usable pixels. This average includes many pixels with little telluric absorption.

The CRIRES+ observation, obtained on 5 April 2022, contains 15 detector-order segments between 3512.8 and 5210.7\,nm. Each segment is fitted independently using quadratic continuum and wavelength-correction models and a Gaussian instrumental profile whose width scales with wavelength. Both programs use uncertainty-weighted least squares and matched molecular inclusion and fitted-species choices. Fitting excludes 30 pixels at each segment edge, the broad source feature at 4050--4056\,nm, and three withheld wavelength blocks per segment. Each program is fitted from three initial Gaussian widths, retaining its lowest fitting-region chi-square.

The bottom figure shows the CRIRES+ windows at 3740--3830 and 4007.7--4103\,nm. The transmissions largely overlap, with small systematic offsets and localised differences. Across the full coverage, including fitted and withheld pixels, $\langle|\Delta|\rangle=0.01060$ over 29\,019 usable pixels. A larger disagreement remains near 5150--5175\,nm, outside the displayed windows. These comparisons measure consistency between the programs, not absolute correction accuracy.

\section{Discussion}

The HARPS comparison demonstrates closely comparable corrections for the tested observation, both around selected stellar features and across the full spectrum. The CRIRES+ comparison extends the assessment to infrared wavelengths and reveals more variable agreement. \Pymolfit\ has a lower average deviation from the shared continuum, although either method is closer in individual wavelength intervals.

\Pymolfit's main contribution concerns implementation and workflow rather than a new physical description of atmospheric absorption. Its Python interface combines atmospheric modelling, parameter estimation, and correction. Automatic fitting-region selection and optional stellar exclusions reduce manual preparation, while the interactive editor allows these choices to be inspected and adjusted. These capabilities facilitate integration into existing Python analysis pipelines.

The quantitative assessment remains limited to one HARPS observation and one CRIRES+ extraction. Other applications have produced qualitatively satisfactory corrections but are not quantitatively assessed here. Broader performance across spectral types, instrumental configurations, and atmospheric conditions therefore remains to be established.

Neither comparison provides independent ground truth. Shared atmospheric inputs and spectroscopic data can produce common errors, while noise, source-spectrum mismatch, and extraction artifacts contribute to the deviations. The CRIRES+ reference additionally depends on both fitted transmissions and represents a smooth continuum rather than a stellar spectrum. Its deviations therefore measure consistency with that reference and are not directly equivalent to the HARPS stellar-template deviations. These comparisons assess agreement with \molecfit\ under the tested conditions, rather than establishing absolute correction accuracy or general superiority.

\section{Software and availability}

\Pymolfit's original Python code is released under the BSD 3-Clause licence. The source code, documentation, tutorial notebooks, and issue tracker are available on GitHub\footnote{\url{https://github.com/nikolasvalsamidis97/PyMolFit}}. The package supports Python 3.10 and later and can be installed from PyPI\footnote{\url{https://pypi.org/project/pymolfit/}} using \texttt{pip install pymolfit}. Installation and usage instructions, including optional interactive dependencies, are provided in the documentation.

Scientific datasets and derived coefficient tables retain their upstream licensing and attribution requirements, documented in the repository. The default AER line catalogue is downloaded automatically, verified by checksum, and cached locally rather than bundled with the package.

\section{Conclusions}

We have presented \pymolfit, an independent Python implementation of established model-based telluric correction. The package combines atmospheric modelling, parameter estimation, and correction within a unified interface, supported by automatic fitting-region selection, optional stellar-feature exclusions, and interactive editing.

Comparisons with \molecfit\ using matched inputs show closely comparable corrections for the tested HARPS observation, both around selected stellar features and across the full spectrum. The full CRIRES+ comparison reveals wavelength-dependent differences, with a lower average deviation for \pymolfit\ from the shared smooth continuum reference.

These comparisons assess consistency under the tested conditions rather than absolute correction accuracy. In particular, the CRIRES+ reference depends on both fitted transmissions, while noise and reference mismatch contribute to the deviations in both datasets. Further validation across observations, instrumental configurations, and atmospheric conditions is needed to establish broader performance. \Pymolfit\ provides an open-source Python framework for this continued assessment and for integration into spectroscopic analysis workflows.
