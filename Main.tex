\section{Introduction}

Ground-based astronomical spectra are affected by absorption in the Earth’s atmosphere. These telluric absorption features contaminate the observed spectrum and can interfere with the detection and analysis of astrophysical spectral lines, particularly when stellar and atmospheric features overlap in wavelength. Accurate modelling and correction of telluric absorption is therefore an essential step in the reduction and interpretation of many spectroscopic observations.

\section{PyMolFit framework}

PyMolFit is an independent pure-Python package for model-based telluric correction of astronomical spectra. The software combines physically based atmospheric modelling with radiative-transfer calculations and spectroscopic molecular databases to estimate the atmospheric transmission and produce a telluric-corrected estimate of the astronomical spectrum.

While several software packages for telluric correction are already available, PyMolFit was developed to provide an independent and extensible framework that integrates naturally into modern astronomical data-analysis workflows. Python is widely used for astronomical data reduction and analysis, with widely adopted libraries such as NumPy, SciPy, and Astropy forming the foundation of many reduction pipelines and analysis tools, implementing the complete telluric-correction workflow within the Python ecosystem enables direct integration into existing scientific software. The modular design of PyMolFit further facilitates validation, maintenance, and future development, allowing individual physical models and numerical components to be extended or replaced while preserving the overall framework.

\subsection{Relationship to Molecfit}
PyMolFit builds upon the physical methodology established by \Molecfit\ \citep{MOLECFIT1,MOLECFIT2}, adopting the same general approach to model-based telluric correction based on atmospheric modelling and line-by-line radiative-transfer calculations. Rather than interfacing with or executing Molecfit itself, PyMolFit provides an independent implementation of these methods written entirely in Python. The software therefore reproduces the overall modelling philosophy while allowing tighter integration with modern Python-based astronomical analysis workflows.

PyMolFit is not intended to be a bit-for-bit reproduction of either Molecfit or LBLRTM. It uses an independent numerical implementation, and remaining differences in the radiative-transfer and optimization procedures are evaluated in Sect.~\ref{sec:validation}.

PyMolFit exposes the telluric-correction workflow through a unified Python API that accepts spectrum files, loaded spectrum objects, or wavelength--flux arrays. The public workflow includes automatic segmentation while preserving physical detector or order groups, automatic and interactive fit-region selection, and optional treatment of theoretical stellar spectra through feature masking or a joint
stellar--telluric forward model. PyMolFit does not introduce a new atmospheric-spectroscopy formalism; instead, it implements established atmospheric and line-by-line radiative-transfer methods in Python without executing the Molecfit or LBLRTM software.

\subsection{Public workflow and software design}

PyMolFit provides a single entry point, \texttt{correct()}, for correcting spectrum files, loaded spectrum objects, or wavelength--flux arrays. All input routes use the same correction pipeline. PyMolFit handles tasks such as numerical segmentation, atmospheric-profile construction, fit-region processing, and model selection using metadata obtained from the input file or supplied explicitly by the user. The returned result contains the corrected spectrum, fitted atmospheric transmission, diagnostic information, and provenance. The default workflow is automated, while the principal modelling and fitting parameters can be configured explicitly.

\section{Methodology}

\subsection{Overall workflow}
\pymolfit first converts the input spectrum and its observational metadata into a standardised internal representation while preserving uncertainties, quality flags, and detector or spectral-order structure. It then constructs an atmospheric profile, calculates a high-resolution transmission spectrum, transforms this model to the observational domain, and fits it to the selected pixels. The fitted transmission is finally evaluated across the complete spectrum and used to produce the telluric-corrected output.

\subsection{Atmospheric modelling}
The observational metadata are subsequently used to construct a layered atmospheric profile above the observatory. PyMolFit combines a \MIPAS \citep{MIPAS} reference atmosphere with \GDAS \citep{GDAS} pressure, temperature and water-vapour data. When available, time-local \GDAS profiles are interpolated to the observation time; otherwise, an appropriate average profile is used. Surface meteorological measurements from the spectrum metadata are incorporated into the lowest atmospheric layers. The resulting profile provides the pressure, temperature, molecular composition and line-of-sight column density of each layer required by the radiative-transfer calculation.

The \MIPAS and \GDAS quantities are interpolated onto a common altitude grid extending from the observatory to the upper atmosphere. \GDAS determines the pressure, temperature, and water-vapour abundance below approximately \(20\,\mathrm{km}\). Between \(20\) and \(26\,\mathrm{km}\), these quantities are gradually blended into the corresponding \MIPAS values to avoid a discontinuity between the lower- and upper-atmosphere profiles. Above this transition, the atmosphere is described by \MIPAS. The vertical distributions of the remaining molecular species are taken from \MIPAS throughout the profile.

Surface pressure, temperature, and relative humidity, when available, are used to modify the profile near the observatory. Their differences from the initial merged atmosphere are progressively reduced with altitude, rather than being applied as a constant offset to the complete profile. Relative humidity is converted into a water-vapour volume-mixing ratio using the local pressure and temperature. This anchors the lowest atmospheric layers to the conditions measured during the observation while retaining the large-scale vertical structure supplied by \GDAS and \MIPAS.

The atmospheric levels are subsequently converted into finite layers. Pressure, total number density, and molecular number densities are interpolated between adjacent altitude levels, and density-weighted mean pressure and temperature values are calculated for each layer. The total air number density follows the ideal-gas relation
\begin{equation}
    n_i = \frac{P_i}{k_{\mathrm{B}}T_i},
\end{equation}
where \(P_i\), \(T_i\), and \(n_i\) are the pressure, temperature, and total number density of layer \(i\), respectively. For a molecular species \(s\) with volume-mixing ratio \(x_{s,i}\), its layer column density is obtained from
\begin{equation}
    N_{s,i} = \int_{\mathrm{layer}\ i} x_s(h)\,n(h)\,\mathrm{d}s .
\end{equation}

The integration path \(\mathrm{d}s\) represents the actual line of sight rather than only the vertical layer thickness. It is calculated from the observation airmass using a spherical atmospheric geometry, with atmospheric refraction included in the standard configuration. Consequently, each layer is assigned both a vertical thickness and an effective slant path length. This treatment becomes increasingly important at large zenith distances, where simply multiplying every vertical column by a constant airmass provides a less accurate representation of the ray path.

At this stage, the atmosphere is represented by a sequence of layers containing the thermodynamic conditions, molecular abundances, and slant columns required for radiative transfer. The profile itself does not yet contain wavelength-dependent absorption. That dependence is introduced in the following step by evaluating the molecular transitions and atmospheric continuum processes within each layer.

\subsection{Molecular absorption and atmospheric continua}
Molecular absorption is calculated on a wavelength grid finer than the observed detector sampling. Relevant transitions are selected from the AER \citep{AER} molecular catalogue, and their temperature-dependent strengths, pressure shifts, Doppler widths and collision-broadened widths are evaluated independently in every atmospheric layer. The resulting Voigt profiles are multiplied by the corresponding molecular columns and summed over all lines and layers. This produces a species-resolved optical-depth model, from which the intrinsic high-resolution atmospheric transmission is obtained through the Beer–Lambert relation \(T(\lambda)=\exp[-\tau(\lambda)]\) \citep{RYBICKI1979}.

For a transition \(j\), the AER catalogue specifies the reference line centre \(\tilde{\nu}_{0,j}\), line intensity \(S_j(T_{\mathrm{ref}})\), lower-state energy \(E_j''\), pressure-broadening coefficients, pressure-shift coefficient, temperature exponent, molecular mass, and isotopologue identity. The catalogue intensity is converted from its reference temperature, normally \(T_{\mathrm{ref}}=296\,\mathrm{K}\), to the temperature \(T_i\) of atmospheric layer \(i\) according to
\begin{equation}
\begin{split}
S_j(T_i) ={}& S_j(T_{\mathrm{ref}})
\frac{Q_j(T_{\mathrm{ref}})}{Q_j(T_i)}
\exp\left[
-c_2 E_j''
\left(
\frac{1}{T_i}-\frac{1}{T_{\mathrm{ref}}}
\right)
\right] \\
&\times
\frac{1-\exp(-c_2\tilde{\nu}_{0,j}/T_i)}
     {1-\exp(-c_2\tilde{\nu}_{0,j}/T_{\mathrm{ref}})},
\end{split}
\end{equation}
where \(Q_j(T)\) is the isotopologue-specific partition function and \(c_2=hc/k_{\mathrm{B}}\) is the second radiation constant. The exponential term accounts for the temperature-dependent population of the lower energy state, while the final ratio accounts for stimulated emission.

The line centre is displaced from its reference value by interactions with the surrounding gas. The applied pressure-shift convention depends on the source and processing path of the line data. For traditional HITRAN text data, the shifted centre in atmospheric layer \(i\) is
\begin{equation}
    \tilde{\nu}_{j,i}
    =
    \tilde{\nu}_{0,j}
    +
    \delta_j P_i ,
\end{equation}
where \(\delta_j\) is the catalogue pressure-shift coefficient and \(P_i\) is expressed in atmospheres. For the default AER/LNFL/LBLRTM path, the shift is instead scaled by the atmospheric number-density ratio,
\begin{equation}
    \tilde{\nu}_{j,i}
    =
    \tilde{\nu}_{0,j}
    +
    \delta_j P_i
    \frac{T_{\mathrm{ref}}}{T_i},
\end{equation}
where \(T_{\mathrm{ref}}=296\,\mathrm{K}\). When broadener-specific information is available, \pymolfit additionally accounts for the relative abundances and pressure-shift coefficients of the relevant collision partners.

Thermal motion produces a Gaussian contribution to the line profile, with a Doppler standard deviation
\begin{equation}
    \sigma_{\mathrm{D},j,i}
    =
    \tilde{\nu}_{j,i}
    \sqrt{\frac{k_{\mathrm{B}}T_i}{m_jc^2}},
\end{equation}
where \(m_j\) is the molecular mass. Collisions produce a Lorentzian contribution whose half-width at half maximum is approximated by
\begin{equation}
    \gamma_{\mathrm{L},j,i}
    =
    P_i
    \left[
        (1-x_{s,i})\gamma_{\mathrm{air},j}
        +
        x_{s,i}\gamma_{\mathrm{self},j}
    \right]
    \left(\frac{T_{\mathrm{ref}}}{T_i}\right)^{n_j},
\end{equation}
where \(x_{s,i}\) is the absorber mixing ratio, \(\gamma_{\mathrm{air},j}\) and \(\gamma_{\mathrm{self},j}\) are the air- and self-broadening coefficients, and \(n_j\) is the temperature exponent. Broadener-specific coefficients are used when they are available in the AER data.

The Gaussian and Lorentzian contributions are combined into a
normalised Voigt profile \(\phi_{j,i}(\tilde{\nu})\). The line optical depth contributed by species \(s\) is consequently
\begin{equation}
    \tau_{s,\mathrm{line}}(\tilde{\nu})
    =
    \sum_i N_{s,i}
    \sum_{j\in s}
    S_j(T_i)\,
    \phi_{j,i}(\tilde{\nu}),
\end{equation}
where \(N_{s,i}\) is the line-of-sight molecular column of species \(s\) in atmospheric layer \(i\). When line-coupling information is available in the AER catalogue, its pressure-dependent corrections to the line strength, width and profile shape are also included.

The complete atmospheric optical depth is expressed as
\begin{equation}
    \tau_{\mathrm{atm}}(\tilde{\nu})
    =
    \sum_r q_r\,\tau_r(\tilde{\nu}),
\end{equation}
where each basis component \(r\) contains the line and continuum contributions that share a common scaling parameter \(q_r\). For example, the water-vapour line and continuum optical depths are combined into the same basis component. Components that cannot be constrained by the selected fitting pixels remain fixed at their initial scales.

The default calculation follows an LBLRTM-style \citep{LBLRTM} panel treatment of the Voigt profiles and their extended wings. Opacity is accumulated on successively coarser grids away from each line centre, while a far-wing contribution retains the collective effect of distant lines. This avoids applying one arbitrary wavelength cut-off to every transition and allows dense groups of individually weak lines to contribute to the total opacity. Lines whose estimated optical-depth contribution is numerically negligible may be screened from the detailed calculation.

Discrete transitions alone do not describe all atmospheric extinction. Broad absorption produced by unresolved line wings and intermolecular interactions is represented by atmospheric continuum components. For water vapour, \pymolfit includes self and foreign continuum absorption: the self component depends on interactions between water molecules, whereas the foreign component describes interactions between water and the remaining atmospheric gas. A corresponding carbon-dioxide continuum is included when \(\mathrm{CO_2}\) is modelled. Additional collision-induced absorption from molecular pairs, \(N_2\) and \(O_2\) continuum branches, and Rayleigh scattering can be enabled when required. These atmospheric continua are distinct from the polynomial spectral continuum introduced later to represent the broad shape of the observed source spectrum.

All enabled contributions are additive in optical depth. The total high-resolution optical depth can therefore be expressed as
\begin{equation}
    \tau_{\mathrm{atm}}(\tilde{\nu})
    =
    \sum_s q_s\,\tau_s(\tilde{\nu})
    +
    \tau_{\mathrm{cont}}(\tilde{\nu}),
\end{equation}
where \(q_s\) is the abundance-scaling parameter for species \(s\). These scaling parameters initially equal unity and are subsequently adjusted during fitting.

The resulting transmission is a dimensionless, intrinsic atmospheric spectrum evaluated at high spectral resolution. It does not yet include residual errors in the observational wavelength solution, broadening by the spectrograph, or integration over finite detector pixels. Furthermore, it describes only the fraction of incident light transmitted through the atmosphere and therefore does not reproduce the broad flux distribution of the astronomical source. These atmospheric and observational representations must be combined before the model can be compared directly with the measured spectrum.

\subsection{Instrumental, wavelength, and continuum modelling}
The intrinsic transmission spectrum is subsequently transformed to the observational domain. A wavelength-correction model accounts for residual errors in the spectral wavelength solution, while convolution with a parameterised line-spread function represents the finite instrumental resolution. The transmission is projected onto the detector grid using overlap-weighted integration and instrumental convolution. Finally, a smooth polynomial continuum converts the dimensionless transmission spectrum into a model of the observed flux. This produces a forward model with the same wavelength sampling as the input spectrum, whose molecular, wavelength, instrumental and continuum parameters are optimized in the following fitting stage.

The wavelength correction applied at this stage is distinct from the deterministic conversion between air and vacuum wavelengths or between barycentric and observatory reference frames. Those conversions are performed during input standardisation. The fitted correction instead accounts for small residual inaccuracies in the wavelength calibration of the reduced spectrum.

For a spectral interval with central wavelength \(\lambda_{\mathrm{c}}\), a normalised wavelength coordinate can be defined as
\begin{equation}
    x(\lambda)
    =
    \frac{2(\lambda-\lambda_{\mathrm{c}})}
         {\lambda_{\max}-\lambda_{\min}}.
\end{equation}
The residual wavelength correction is represented by
\begin{equation}
    \Delta\lambda(\lambda)
    =
    \sum_{k=0}^{p} a_k x(\lambda)^k ,
\end{equation}
where \(a_k\) are the wavelength coefficients and \(p\) is the selected polynomial order. A zeroth-order model represents a constant displacement, while higher orders allow the displacement to vary smoothly across the spectrum. The correction may be expressed directly in wavelength units or in detector pixels, in which case the local pixel dispersion converts it into a wavelength displacement. For multi-order spectra, independent corrections may be assigned to individual orders or detector groups. The optical-depth model is then evaluated at the corrected coordinates,
\begin{equation}
    \tau_{\mathrm{shift}}(\lambda)
    =
    \tau\!\left[\lambda-\Delta\lambda(\lambda)\right].
\end{equation}
This operation aligns the atmospheric absorption with the observation without modifying the wavelength array stored in the final output.

The line-spread function describes how the spectrograph redistributes monochromatic incident light over neighbouring detector pixels. \pymolfit represents it using a normalised composite kernel that may contain Gaussian, Lorentzian, and boxcar components. The Gaussian component describes the central instrumental broadening associated with the resolving power, the Lorentzian component allows extended instrumental wings, and the boxcar component represents a finite slit width or another approximately rectangular instrumental response. Conceptually, the instrumentally broadened transmission is
\begin{equation}
    T_{\mathrm{LSF}}(\lambda)
    =
    \int
    T_{\mathrm{atm}}(\lambda')
    K(\lambda-\lambda';\boldsymbol{\theta}_{\mathrm{LSF}})
    \,\mathrm{d}\lambda',
\end{equation}
where \(K\) is the normalised line-spread function and
\(\boldsymbol{\theta}_{\mathrm{LSF}}\) contains its width parameters.

The instrumental width can be held constant in detector pixels or allowed to vary smoothly with wavelength according to
\begin{equation}
    w(\lambda)
    =
    w_{\mathrm{ref}}
    \left(
        \frac{\lambda}{\lambda_{\mathrm{ref}}}
    \right)^{\alpha},
\end{equation}
where \(w_{\mathrm{ref}}\) is the width at the reference wavelength and \(\alpha\) controls its wavelength dependence. Initial widths can be estimated from the resolving power recorded in the spectrum metadata or, when this information is unavailable, from the widths of suitable narrow features in the observation.

The transformed transmission must also account for the finite wavelength interval represented by each detector pixel. If pixel \(p\) spans the interval
\([\lambda_{p,-},\lambda_{p,+}]\), its model transmission is represented by the pixel average
\begin{equation}
    T_p
    =
    \frac{1}{\lambda_{p,+}-\lambda_{p,-}}
    \int_{\lambda_{p,-}}^{\lambda_{p,+}}
    T_{\mathrm{LSF}}(\lambda)\,\mathrm{d}\lambda .
\end{equation}
Using pixel integration rather than sampling only at the pixel centre is important for unresolved or nearly saturated lines, for which the transmission may vary considerably within a single detector pixel. The overlap-weighted implementation also preserves detector boundaries, spectral-order separation, and gaps in wavelength coverage.

After these transformations, \(T_p\) has the same sampling as the observed spectrum but remains dimensionless. A multiplicative polynomial continuum is therefore introduced to describe the broad flux distribution of the astronomical source and the slowly varying instrumental response. For a polynomial of degree \(m\),
\begin{equation}
    C_p
    =
    \sum_{k=0}^{m} c_k x_p^k ,
\end{equation}
where \(c_k\) are continuum coefficients and \(x_p\) is the normalised wavelength coordinate. Separate continuum polynomials are used for independently fitted spectral segments, avoiding the requirement that one polynomial describe disconnected orders or broad wavelength gaps.

The standard forward model at detector pixel \(p\) is consequently
\begin{equation}
    F_{\mathrm{model},p}
    =
    C_p\,T_p .
\end{equation}
When a theoretical stellar spectrum is supplied, its predicted stellar features are excluded from atmospheric parameter estimation by default. In the optional joint stellar--telluric mode, the forward model instead becomes
\begin{equation}
    F_{\mathrm{model},p}
    =
    C_p\,
    \mathcal{L}_p
    \left[
        S(\lambda)T_{\mathrm{atm}}(\lambda)
    \right],
\end{equation}
where \(S(\lambda)\) is the normalised theoretical stellar spectrum and \(\mathcal{L}_p\) represents instrumental convolution and integration over detector pixel \(p\). The corresponding correction removes only the atmospheric contribution and does not divide out the stellar spectrum.
The continuum is deliberately restricted to smooth variations and is not intended to reproduce narrow stellar or circumstellar lines. Such features are normally excluded from the fitting pixels or, when a theoretical stellar spectrum is supplied, represented by the optional stellar forward model.

These operations define how a proposed set of molecular, wavelength, instrumental, and continuum parameters is converted into a model on the observed detector grid. The remaining task is to determine which parameter values provide the best agreement with the measured flux.


\subsection{Optimisation}
The atmospheric and instrumental parameters are determined through bounded non-linear least-squares optimization. At each iteration, the species-resolved optical depths are scaled and combined, converted into transmission, wavelength corrected, convolved with the instrumental line-spread function, and re-binned onto the observed detector grid. A polynomial continuum converts the transmission into a model flux, which is compared with the observation over the selected fitting pixels. Molecular columns, wavelength coefficients and instrumental widths are iteratively updated until the residuals or parameter changes satisfy the convergence criteria.

The thermodynamic structure of the atmosphere is held fixed during this stage. The adjustable atmospheric quantities are primarily multiplicative scale factors applied to the optical-depth contribution of each fitted molecular species. These factors are optimized logarithmically, which guarantees positive molecular columns while allowing physically motivated bounds to be imposed. Depending on the selected configuration, the parameter vector may additionally contain global or order-dependent wavelength-polynomial coefficients, Gaussian and Lorentzian line-spread-function widths, and coefficients describing the wavelength dependence of the instrumental resolution.

The optimization is restricted to a fitting mask, denoted by \(\mathcal{F}\), containing valid pixels inside the selected fit regions and outside all exclusion regions. For a pixel \(i\), the weighted residual is
\[
r_i =
\sqrt{w_i}\,
\frac{F_{\mathrm{obs},i}-F_{\mathrm{model},i}(\boldsymbol{\theta})}
{\sigma_i},
\qquad i\in\mathcal{F},
\]
where \(F_{\mathrm{obs},i}\) and \(\sigma_i\) are the observed flux and uncertainty, \(w_i\) is an optional confidence weight, and \(\boldsymbol{\theta}\) contains the fitted parameters. With the standard linear loss, the minimized objective is
\[
\chi^2(\boldsymbol{\theta}) =
\sum_{i\in\mathcal{F}} r_i^2.
\]
Robust loss functions may instead be used to reduce the influence of outliers, unmasked astrophysical features, cosmic rays, or defective pixels.

For a given set of non-linear atmospheric, wavelength and instrumental parameters, the continuum coefficients may be determined conditionally through weighted linear least squares. This reduces the dimensionality of the non-linear problem and prevents the continuum parameters from unnecessarily slowing the optimization. For spectra containing multiple orders or discontinuous detector segments, molecular scale factors may be shared across the observation, while continuum and wavelength terms can be assigned locally according to the selected fitting model.

Initial wavelength and instrumental parameters can be estimated through coarse pilot searches before the full optimization. The bounded least-squares calculation then proceeds until the relative change in the objective function, the parameter-step size or the gradient satisfies its corresponding convergence tolerance, or until the maximum number of model evaluations is reached. When requested, parameter uncertainties are estimated locally from the weighted Jacobian around the optimum. These uncertainties describe the statistical curvature of the fitted model and do not include systematic errors in the atmospheric profile, molecular catalogue or instrumental parameterisation.

The optimization therefore returns a single consistent set of molecular, wavelength, instrumental and continuum parameters inferred only from the selected fitting pixels. Once these parameters have converged, the fitting mask has completed its role and the optimized model can be propagated over the full observational wavelength domain.


\subsection{Outputs}
Following convergence, the fitting masks are removed and the optimized atmospheric, wavelength and instrumental parameters are applied over the complete spectral range. The high-resolution transmission is recomputed, convolved with the fitted line-spread function and re-binned onto every valid detector pixel. Fit and exclusion regions therefore affect parameter estimation only; atmospheric transmission is still evaluated within excluded regions and outside the intervals used for fitting. This produces the final detector-sampled transmission spectrum used for telluric correction.

The telluric-corrected spectrum is obtained by dividing the observed flux by the optimized detector-sampled atmospheric transmission. The original wavelength sampling, spectral-order structure and detector gaps are retained, while observational and model uncertainties are propagated through the division. Pixels with transmission below a specified threshold are masked because the atmospheric absorption has removed too much information for a stable correction. The final product includes the corrected flux together with the fitted transmission, model parameters, masks and provenance information.

For every detector pixel that passes the correction mask, the corrected flux is therefore
\[
F_{\mathrm{corr},i}
=
\frac{F_{\mathrm{obs},i}}{T_i},
\]
where \(T_i\) is the optimized atmospheric transmission after application of the fitted wavelength and instrumental response. The wavelength correction is applied to the atmospheric model rather than to the observed spectrum. Consequently, the scientific flux is not resampled by the fitted residual wavelength correction. The returned wavelength array remains on PyMolFit's standardised vacuum, observatory-frame grid, while the original pixel, detector, and spectral-order structure is preserved.

When both observational and transmission uncertainties are available, the corrected uncertainty is propagated as
\[
\sigma_{\mathrm{corr},i}^{2}
=
\left(\frac{\sigma_{F,i}}{T_i}\right)^2
+
\left(\frac{F_{\mathrm{obs},i}\sigma_{T,i}}{T_i^2}\right)^2,
\]
assuming that the observational and model uncertainties are independent. If no transmission uncertainty has been estimated, only the first term is retained. This expression also illustrates why corrections become unstable at low transmission: both observational noise and atmospheric-model errors are amplified rapidly as \(T_i\) approaches zero. PyMolFit therefore masks such pixels instead of clipping their corrected values; the standard minimum-transmission threshold is \(T_{\min}=0.01\).

The returned data product preserves the association between each corrected pixel and its original spectral order or detector segment. In addition to the corrected flux, it records the observed flux, detector-sampled transmission, fitted forward model, observational and propagated uncertainties, fitting and correction masks, molecular scale factors, wavelength coefficients, line-spread-function parameters, continuum coefficients and optimization diagnostics. Provenance metadata identify the atmospheric-profile source, molecular catalogue and principal configuration choices used for the calculation.

The corrected spectrum represents the input observation with the fitted atmospheric transmission divided out. Astrophysical features are not removed merely because they were excluded from parameter estimation, and detector gaps or invalid pixels are not interpolated. Similarly, wavelengths affected by saturated atmospheric absorption remain masked because the information removed by the atmosphere cannot be reconstructed reliably. The output consequently retains both the scientific spectrum and the diagnostic information required to evaluate the telluric correction.
