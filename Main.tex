\section{Introduction}

Ground-based astronomical spectra are affected by absorption in the Earth’s atmosphere. These telluric absorption features contaminate the observed spectrum and can interfere with the detection and analysis of astrophysical spectral lines, particularly when stellar and atmospheric features overlap in wavelength. Accurate modelling and correction of telluric absorption is therefore an essential step in the reduction and interpretation of many spectroscopic observations.

\section{PyMolFit framework}

\pymolfit reimplements the core telluric-correction approach used by \Molecfit\ \citep{MOLECFIT1,MOLECFIT2} in Python, with assistance from AI coding tools during development. Atmospheric-profile construction, line-by-line absorption modelling, and fitting the resulting transmission to an observed spectrum follow established methods rather than introducing a new physical formalism. PyMolFit performs these calculations through its own numerical implementation without executing Molecfit or LBLRTM. Its contributions concern the implementation and user workflow: a unified Python interface, automated spectral segmentation and fit-region selection, and optional use of theoretical stellar spectra for identifying exclusion regions or joint stellar--telluric fitting. The following sections describe these capabilities and the numerical differences relevant to interpreting and validating the corrected spectra.

\subsection{Implementation and workflow}
The current Molecfit pipeline separates parameter fitting, transmission calculation over the full spectral range, and telluric correction into the recipes \texttt{molecfit\_model}, \texttt{molecfit\_calctrans}, and \texttt{molecfit\_correct}, respectively. PyMolFit exposes these stages through a single Python function, \texttt{correct()}, which accepts spectrum files, loaded spectrum objects, or wavelength--flux arrays. The function returns the corrected spectrum together with the fitted transmission, model parameters, masks, and diagnostic information.

Whereas \Molecfit uses \LBLRTM for its radiative-transfer calculations \citep{MOLECFIT1}, PyMolFit evaluates the atmospheric absorption through its own numerical implementation. It therefore replaces the computational engine rather than providing a Python interface to the existing Molecfit executables. The underlying physical methods are established, but differences in their numerical implementation and in the optimisation procedure can produce different transmission spectra and fitted parameters. These differences are assessed in Sect.~\ref{sec:validation}.

Within this workflow, PyMolFit provides automatic spectral segmentation, automatic and interactive fit-region selection, and automatic stellar-feature exclusion when a theoretical stellar spectrum is supplied. Numerical segmentation preserves physical spectral-order and detector-group boundaries. The theoretical spectrum is used to identify stellar features and exclude the corresponding wavelength regions from telluric parameter estimation, while atmospheric transmission is still evaluated throughout those regions.
