\section{Introduction}

Ground-based astronomical spectra are affected by absorption in the Earth’s atmosphere. These telluric absorption features contaminate the observed spectrum and can interfere with the detection and analysis of astrophysical spectral lines, particularly when stellar and atmospheric features overlap in wavelength. Accurate modelling and correction of telluric absorption is therefore an essential step in the reduction and interpretation of many spectroscopic observations.

\section{PyMolFit framework}

\pymolfit reimplements the core telluric-correction approach used by \Molecfit\ \citep{MOLECFIT1,MOLECFIT2} in Python, with assistance from AI coding tools during development. Atmospheric-profile construction, line-by-line absorption modelling, and fitting the resulting transmission to an observed spectrum follow established methods rather than introducing a new physical formalism. PyMolFit performs these calculations through its own numerical implementation without executing Molecfit or LBLRTM. Its contributions concern the implementation and user workflow: a unified Python interface, automated spectral segmentation and fit-region selection, and optional use of theoretical stellar spectra for identifying exclusion regions. The following sections describe how these capabilities are implemented and how the resulting telluric correction is validated.

\subsection{Implementation and workflow}
PyMolFit combines parameter fitting, calculation of atmospheric transmission over the full spectral range, and application of the telluric correction into a single Python function, \texttt{correct()}. This function accepts spectrum files, loaded spectrum objects, or wavelength--flux arrays and returns the corrected spectrum together with the fitted transmission, model parameters, masks, and diagnostic information.

PyMolFit automatically divides the spectrum into smaller processing segments while preserving spectral-order and detector-group boundaries. Fitting regions can be selected automatically or defined and edited through an interactive selector. When a theoretical stellar spectrum is supplied, PyMolFit uses it to identify stellar features and exclude the corresponding wavelength regions from telluric parameter estimation. These exclusions affect only the fit: atmospheric transmission is still calculated in the excluded regions when applying the correction.

Whereas \Molecfit uses \LBLRTM for its radiative-transfer calculations \citep{MOLECFIT1}, PyMolFit evaluates the atmospheric absorption through its own numerical implementation. It therefore replaces the computational engine rather than providing a Python interface to the existing Molecfit executables. The underlying physical methods are established, but differences in their numerical implementation and in the optimisation procedure can produce different transmission spectra and fitted parameters. These differences are assessed in Sect.~\ref{sec:validation}.

\section{Methodology}
This section describes the atmospheric model, selection of fitting pixels, and numerical procedures used to estimate and apply the telluric correction.

\subsection{Atmospheric profile and absorption calculation}
In its default configuration, PyMolFit constructs a layered atmosphere above the observatory by combining a MIPAS reference atmosphere \citep{MIPAS_PROFILE} with GDAS pressure, temperature, and water-vapour profiles \citep{GDAS}. Time-local GDAS profiles are interpolated to the observation time when available; otherwise, a monthly average profile is used. Available surface meteorological measurements modify the lowest atmospheric layers. Each layer is assigned a pressure, temperature, and molecular composition. The molecular column \(N_{s,i}\) specifies the number of molecules of species \(s\) per unit area encountered along the line of sight through layer \(i\). The path through each layer is calculated from the observation airmass using spherical atmospheric geometry, including refraction in the default configuration.

Molecular absorption is calculated on an internal spectral grid finer than the observed detector sampling. Transitions are obtained from the AER catalogue \citep{AER}, which provides their reference positions, intensities, and broadening parameters. The catalogue intensity \(S_j(T_{\mathrm{ref}})\) of transition \(j\) describes its absorption cross-section integrated over wavenumber at the reference temperature \(T_{\mathrm{ref}}=296\,\mathrm{K}\) \citep{HITRAN}. For each atmospheric layer, the intensity is adjusted to the local temperature, and the line position and profile are evaluated using the local pressure, temperature, and molecular composition. The profiles account for thermal and collisional broadening. Their contributions are multiplied by the corresponding molecular columns and summed to obtain the wavelength-dependent optical depth, a dimensionless measure of attenuation.

Discrete-line absorption is supplemented by atmospheric continuum contributions, including water-vapour and carbon-dioxide absorption when these species are modelled \citep{MTCKD,LBLRTM}. These describe broad atmospheric absorption beyond the discrete-line contribution. All enabled contributions are combined into the total optical depth \(\tau_{\mathrm{atm}}(\lambda)\), from which the intrinsic atmospheric transmission is
\begin{equation}
    T_{\mathrm{atm}}(\lambda) = \exp[-\tau_{\mathrm{atm}}(\lambda)].
\end{equation}
This Beer--Lambert relation gives the fraction of incident light transmitted through the atmosphere \citep{RYBICKI1979}. Instrumental broadening and the comparison with the observed flux are treated in the subsequent modelling stages.

\subsection{Spectral segmentation and fit-region selection}
\begin{figure*}[t]
    \centering
    \includegraphics[width=\textwidth]{Images/Interactive_selector.png}
    \caption{PyMolFit's interactive region selector showing the observed AU Mic spectrum around the Na\,I D doublet. Green and orange shading indicate automatically selected fitting and stellar exclusion intervals, respectively; exclusions take precedence where they overlap. The right-hand controls allow manual region editing, adjustment of the number of catalogue transitions used to propose fitting intervals, and modification of the stellar-template, broadening, and masking parameters used to regenerate the exclusions. Blue ticks mark H$_2$O transitions from the AER catalogue, providing wavelength references for identifying telluric features.}
    \label{fig:Interactive_selector}
\end{figure*}
PyMolFit preserves the spectral-order and detector divisions of the input data while subdividing their wavelength coverage into smaller intervals for computation. Physical groups are identified from the input metadata or, when these identifiers are unavailable, from large gaps in the wavelength sampling. Each group is subdivided into processing segments with a configurable target wavelength span of 50\,\AA\ by default. Segments are subdivided further if the high-resolution atmospheric model would require more than the permitted number of wavelength points, set to two million per segment by default. This limits memory use without coarsening the model grid or resampling the observed spectrum.

Fitting intervals define which parts of the observed spectrum are used to determine the correction parameters. They can be specified directly, drawn in the interactive selector shown in Fig.~\ref{fig:Interactive_selector}, or proposed automatically around telluric lines from the AER catalogue \citep{AER}. Automatic selection orders the candidate lines by the score
\begin{equation}
    A_j = S_j(T_{\mathrm{ref}})\,N_{s(j),\mathrm{rep}},
\end{equation}
where \(S_j(T_{\mathrm{ref}})\) is the catalogue line intensity and \(N_{s(j),\mathrm{rep}}\) is the column of the corresponding molecule in a fixed reference atmosphere. The score combines the strength of the transition with the approximate amount of that molecule in the atmosphere. A larger score gives a line higher priority for selection.

The requested number of highest-scoring lines within the observed wavelength coverage is selected. A fitting interval is placed around each line, with a configurable half-width in detector pixels. Overlapping intervals are merged, so the final number of intervals may be smaller than the requested number of lines. The user can inspect and edit the proposed intervals before fitting.

Exclusion intervals mark wavelength ranges that should not influence the telluric fit, for example because they contain stellar features or detector defects. They can be specified directly, drawn in the interactive selector, or generated automatically from a theoretical stellar spectrum. An exclusion takes precedence wherever it overlaps a fitting interval.

When a theoretical stellar spectrum is supplied, PyMolFit normalises it using an estimated continuum and broadens it for stellar rotation and instrumental resolution. Its wavelengths are converted to the appropriate wavelength medium and reference frame using the supplied stellar radial velocity and the observation's frame correction. A small residual velocity offset can be refined by cross-correlation with the observed spectrum. Features whose fractional deviation from the template continuum exceeds a configurable threshold are marked for exclusion. Adjacent marked pixels are combined into intervals, and an adjustable velocity padding extends the intervals to allow for line wings and small alignment errors. The detection threshold and padding can be adjusted using the stellar-mask controls shown in Fig.~\ref{fig:Interactive_selector}, and the exclusions regenerated. The resulting intervals can also be edited manually.

Only valid pixels inside the fitting intervals and outside the exclusion intervals contribute to parameter estimation. If no fitting intervals are specified, all valid, non-excluded pixels are used. Both types of interval can be saved together in an ECSV file with their wavelength units, wavelength medium, and reference frame. These selections affect parameter estimation, not the coverage of the correction: atmospheric transmission is also evaluated outside the fitting intervals and within excluded regions.

\subsection{Instrumental, wavelength, and continuum modelling}
PyMolFit transforms the high-resolution atmospheric transmission into a model of the observed flux. A wavelength-correction model accounts for residual misalignment between the predicted telluric lines and the observation, while convolution with an instrumental line-spread function represents the broadening caused by the spectrograph. The broadened transmission is integrated onto the observed wavelength grid without resampling the observation itself. A smooth polynomial continuum, determined locally for each processing segment, then scales the dimensionless transmission to the observed flux level.
